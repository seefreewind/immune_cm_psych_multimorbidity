# Environment notes

The project used Python 3, R/renv environments, LDSC, Genomic SEM, LAVA 0.1.5, `coloc` 5.2.3 and the documented frozen LD references. Exact package and source versions are retained in the project environment and statistical-freeze files. The public release must record the final operating-system, Python, R, matplotlib, pandas, numpy, pypdf and Pillow versions used for figure regeneration.
